# Smile Alatau — лендинг стоматологии в Алматы

Одностраничный сайт: Главная, О нас, Услуги, Контакты. Есть прайс-лист, врачи, отзывы, окно записи на приём (WhatsApp), переключатель языка RU / KZ, светлая и тёмная темы.

## Структура

```
index.html      разметка страницы
css/style.css   стили
js/main.js      язык RU/KZ, модальное окно записи
```

## Запуск локально

Откройте `index.html` в браузере или запустите сервер:

```
npx serve .
```

## Что заменить перед запуском

- Название клиники, адрес, телефон (`index.html`)
- Номер WhatsApp: `77000000000` в `index.html` и `js/main.js`
- Врачи, отзывы и цены (`index.html`)
- Казахский перевод: словарь `KK` в `js/main.js`

## Деплой на Vercel

Сайт статический, сборка не нужна. В Vercel: **Add New → Project → Import** репозитория, Framework Preset: **Other**, Build Command пустой.
